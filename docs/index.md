# FinStats docs

The documentation for **FinStats** and the two libraries it is built from, in one place.

<div class="grid" markdown>

**[FinStats](finstats/index.md)**
: See what your Jellyfin server is really doing: who is watching, what they watch, how it streams, and your year in
  review. One small container, no database server.
  [Get started](finstats/install.md) · [Settings](finstats/settings.md) · [HTTP API](finstats/api.md)

**[FinUI](finui/index.md)**
: The components FinStats is built from: vanilla ES modules and plain CSS, no build step, light and dark from one set
  of tokens. Source you copy and own.
  [Make it yours](finui/create.md) · [Using it](finui/using.md)

**[FinMotion](finmotion/index.md)**
: How FinUI moves, put on top of it: one stylesheet and one call, four springs, still under reduced motion.
  [Install](finmotion/install.md) · [Four springs](finmotion/springs.md)

</div>

## Elsewhere

- [Try the FinStats demo](https://demo.finstats.no/): FinStats in your browser, with invented people and

- [The FinUI gallery and FinUI create](https://finui.finstats.no/), and [the FinMotion site](https://finmotion.finstats.no/).
- The code: [FinStats](https://github.com/finstats/finstats), [FinUI](https://github.com/finstats/finui),

  [FinStats' releases page](https://github.com/finstats/finstats/releases) and in the app's Patch notes tab.
- Questions go to [Discussions](https://github.com/finstats/finstats/discussions); a page here that lost you is a bug,
  [report it on this repository](https://github.com/finstats/docs/issues).
